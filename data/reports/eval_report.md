# 知枢 · 评测报告

> 评测集：内置自建集（10 题，涵盖语义型 / 编号型 / 负样本）
> 判定方式：heuristic(mock)
> **说明**：以下数字仅反映本项目在自建评测集上的表现，非权威基准，不代表通用能力。

## 一、总体指标

| 指标 | 数值 | 含义 |
|---|---|---|
| 忠实度 Faithfulness | 0.000 | 答案是否有可验证的证据支撑（防幻觉） |
| 答案相关性 Answer Relevancy | 0.000 | 答案是否切题 |
| 上下文召回 Context Recall | 1.000 | 所需信息是否被检索到（检索层指标） |
| LLM-as-Judge | 0.000 | 综合正确性评分 |

- 平均延迟：0.4 ms（P95 0.8 ms）
- 本轮总成本：$1e-05
- 拒答正确率：0/2（负样本必须拒答，答了就是幻觉）
